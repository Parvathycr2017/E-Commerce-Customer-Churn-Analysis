# 📊 E-Commerce Customer Churn Analysis

## 📌 Project Overview
This project analyzes customer churn behavior in an e-commerce business. The main objective is to clean, transform, and analyze customer data to identify patterns that lead to customer churn and provide insights that can help improve customer retention.



## 🛠️ Skills & Concepts Covered
- Data Cleaning & Preprocessing
- Handling Missing Values (Mean, Median, Mode)
- Outlier Detection & Removal
- Data Transformation & Feature Engineering
- SQL for Data Analysis
- Business Insights Generation



## 📂 Dataset Description
The dataset contains customer-related information such as:
- Customer demographics
- Order history
- Payment methods
- Tenure and satisfaction scores
- Churn status



## 🧰 Tools Used
- MySQL – for data cleaning, transformation, and analysis
- MySQL Workbench – for executing SQL queries
- GitHub – for version control and project showcasing


## 🔧 Data Cleaning Steps
- Filled missing values using mean, median, and mode
- Removed outliers from specific columns
- Standardized inconsistent values (e.g., payment modes)
- Renamed columns for better readability



## 🔄 Data Transformation
- Created new columns like:
  - `ComplainReceived`
  - `ChurnStatus`
- Dropped unnecessary columns



## 📊 Key Analysis Performed
- Count of churned vs active customers
- Average tenure and cashback for churned users
- Percentage of customers who complained
- City with highest churn rate
- Most preferred payment methods
- Gender-based coupon usage analysis
- Order category preferences
- Satisfaction score analysis
- Customer segmentation based on distance categories



## 📈 Insights Generated
- Identified key factors influencing customer churn
- Found patterns in payment methods and order behavior
- Highlighted customer segments with higher churn risk
